# plugins/shopping

shopping plugin：本项目中**唯一**允许自进化系统修改的编辑面载体（含 Cordis overlay 中显式声明的部分）。

## 第一版计划中的可编辑面

以下六类是第一版规划的显式编辑面；任何候选 patch 只能落在这些面上：

1. **购物系统提示与工作流**
   购物任务的 system prompt、步骤编排与整体工作流描述。

2. **搜索与候选筛选策略**
   查询构造、搜索调用策略、候选商品的筛选与排序规则。

3. **购买前证据核验**
   下单前必须收集与核验的证据（库存、可售状态、评价、卖家信息等）及其通过条件。

4. **variant/规格与最终价格复查**
   规格/variant 选择确认、最终成交价（含优惠/运费）与预算约束的复核逻辑。

5. **guard 拒绝、重复动作、工具失败恢复**
   guard 拒绝后的处理、重复动作检测与抑制、工具调用失败后的重试与恢复策略。

6. **探索预算、循环控制与终止策略**
   每任务的探索/步数预算、循环上限与退出条件、任务成功/放弃的终止判定。

## 编辑面之外

- 编辑面之外的任何改动（DSH 核心、模型 adapter、基础工具执行、ShopSimulator）一律禁止。
- 每个候选 patch 必须可 diff、可回放、可回滚、可审计（见根 README）。
